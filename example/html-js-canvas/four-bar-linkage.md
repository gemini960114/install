幫我做一個曲柄搖桿機構的動畫,用 HTML 加 JavaScript 就好,單一個檔案,打開瀏覽器就能看。整個專案建在 `D:\antigravity\four-bar-linkage-canvas`。

畫面上要有一個滑桿,拖動的話可以控制曲柄轉動的角度,然後畫面即時畫出整組連桿的樣子,曲柄、連桿、搖桿都要看得出來是三根不同的線段,轉動的時候看起來要像真的機構在動一樣。長度自己挑就好,但要挑一組真的能讓曲柄整圈轉、搖桿來回擺動的長度(符合曲柄搖桿機構的比例條件),不要挑到轉一半就卡住的組合。

如果可以的話,搖桿末端(或連桿上隨便一個耦合點)移動的軌跡也順便畫出來,讓人可以看到那個點跑出來的曲線形狀。介面不用太複雜,能看懂在動就好。
