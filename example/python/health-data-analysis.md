幫我抓衛福部疾管署的登革熱病例統計資料,去 data.gov.tw 或 data.cdc.gov.tw 上找「登革熱」相關的資料集,下載下來分析一下。整個專案放在一個叫 `health-data-analysis` 的資料夾裡。

想看兩個東西:

1. 各縣市病例數排名——用長條圖畫出每個縣市的病例總數,一眼就能看出哪幾個縣市疫情比較嚴重(大概猜得到是南部縣市會比較高,像台南、高雄)
2. 時間趨勢——選病例數最多的那個縣市,畫出它逐月的病例數變化,看有沒有明顯的季節性高峰(通常夏天蚊子多的時候會爆發)

用 requests 抓資料、pandas 整理、matplotlib 畫圖,兩張圖分開存成圖片檔。環境用 uv 管理。
