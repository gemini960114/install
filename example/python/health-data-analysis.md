### 執行與環境設定
1. 環境一律用 `uv` 管理：
   - 建立虛擬環境：`uv venv`
   - 安裝所需套件：`uv pip install requests pandas matplotlib`
   - 執行程式：`uv run analyze_dengue.py`
2. 資料來源處理：
   - 疾管署歷史確定病例資料集若遇政府開放平臺結構調整，可使用官方開放資料之 GitHub 鏡像庫（`rwepa/DataDemo` 的 `Dengue_Daily.csv`）下載。
   - 用 `requests` 下載後快取到本地 `data/dengue_daily.csv`，避免重複抓取。

### 分析與繪圖需求（用 pandas 整理、matplotlib 畫圖，兩張圖分開存成圖片檔）
1. **各縣市病例數排名**：
   - 抓具代表性的大流行年份（如 2015 年）或近年的確定病例資料。
   - 統計全台每個縣市的病例總數並由大到小排序。
   - 用長條圖畫出各縣市病例數，第一、二名用顯眼顏色標記，其餘縣市用柔和色系，並在柱狀上方標註數值，一眼就能看出哪幾個縣市疫情最嚴重（南部縣市如台南市、高雄市合計佔全台九成以上）。
   - 存成 `county_ranking.png`。

2. **時間趨勢與季節性分析**：
   - 選出病例數最多的那個縣市（台南市），計算它 1 到 12 月逐月的確定病例數變化。
   - 畫出折線圖並在線條下方加上半透明填色，標出各月份數據點與數值。
   - 特別在最高峰月份（通常是 8 到 10 月夏秋蚊子多的時候）加上箭頭與文字標籤，清楚標示季節性高峰。
   - 存成 `monthly_trend.png`。

3. **中文字型處理**：
   - 在 matplotlib 設定使用繁體中文字型（如微軟正黑體 `Microsoft JhengHei`），並設定負號正常顯示，避免圖表上的中文和符號變成方塊亂碼。
