# GitHub CLI (gh) 安裝指南

---

## Linux

```bash
# Debian / Ubuntu
sudo apt-get update && sudo apt-get install -y gh

# CentOS / RHEL / Fedora
sudo yum install -y gh
```

---

## macOS

```bash
brew install gh
```

---

## Windows

```cmd
winget install --id GitHub.cli
```

---

## 驗證安裝與登入

```bash
gh --version
gh auth login
```
